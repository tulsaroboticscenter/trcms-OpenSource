# README screenshots

Drop four PNGs here with these exact names, and they'll appear in the main README's
**Screenshots** section. Capture them from a running instance.

| File | Page | What it shows |
|------|------|---------------|
| `01-login.png`      | `/login`            | Sign-in screen + your org branding (wordmark/logo, tagline) |
| `02-modules.png`    | `/admin/modules`    | Turning modules on/off for the whole org |
| `03-compliance.png` | `/admin/compliance` | Renaming/configuring the compliance items that gate check-in |
| `04-programs.png`   | `/admin/programs`   | Program list (FLL/FTC/FRC/FDP or your own) |

**Keep them free of personal data.** These four pages are configuration/chrome and show
no member information. Avoid screenshotting the member directory, rosters, or reports
(they display real names). A fresh install (seeded by `deploy/seed_base.sql`, no members)
is the cleanest source; a demo DB (`deploy/seed_dev.php`, synthetic data) also works.

Recommended width ~1200–1440px. PNG preferred.
